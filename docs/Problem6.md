# Problem 6：基础 UI 状态、方向图标和当前玩家高亮

## 问题背景

当前对战 UI 中，一些基础视觉状态不够清晰：

1. 顺时针 / 逆时针只是文字，不够直观。
2. 轮到玩家时的背景高亮不够明显。
3. 玩家状态、按钮状态、座位表现还不够游戏化。
4. 部分 UI 信息没有形成明确层级。

本问题对应原问题：

- 6. 顺时针逆时针画一个 UI 表示，不要直接用文字
- 7. 轮到玩家时背景高亮不够明显
- 19. 出局和获胜需要弹窗
- UI Design Spec 中关于座位、头像、中央牌桌和玩家状态的要求

## 本阶段目标

优化基础 UI 表现：

1. 用图标表示顺时针 / 逆时针。
2. 当前玩家座位高亮更明显。
3. 玩家座位显示更清楚的头像、昵称、手牌数和状态。
4. 操作按钮状态更明确。
5. 出局、胜利、当前回合等信息更容易读。
6. 不做大规模 UI 重写，但让当前界面更像牌类游戏。

## 不要做什么

本阶段不要做：

- 不改核心规则。
- 不做复杂动画。
- 不做完整牌桌重构。
- 不做数据库、登录、商城、支付。
- 不重写客户端架构。
- 不破坏已有 data-testid。

## 需要检查的文件

请优先审计：

1. `apps/client-web/src/main.ts`
2. `apps/client-web/src/styles.css`
3. `apps/client-web/src/cards/cardAssets.ts`
4. `packages/shared-types/src/snapshot.ts`
5. `packages/shared-types/src/player.ts`

## 任务 1：方向图标化

当前问题：

```txt
顺时针 / 逆时针用文字显示，不够直观。

要求：

1. 用环形箭头图标表示方向。
2. 顺时针显示 clockwise icon。
3. 逆时针显示 counter-clockwise icon。
4. 当前方向高亮。
5. 反转牌打出后方向图标变化明显。

可以用：

CSS 绘制箭头
SVG 图标
纯文本符号 + 样式包装

但不要只显示：

clockwise
counter-clockwise
任务 2：当前玩家高亮增强

当前问题：

轮到玩家时背景高亮不够明显。

要求：

1. 当前玩家座位背景更亮。
2. 头像外圈有明显高亮。
3. 显示“当前行动”徽标。
4. 可以有轻微呼吸效果，但不要过度闪烁。
5. 本地玩家回合时，自己的操作区也要更明显。

建议视觉：

头像外圈发光
座位卡片边框变亮
当前行动标签
桌面状态栏显示“轮到 xxx”
任务 3：玩家座位状态徽标

每个玩家座位建议显示：

头像
昵称
手牌数
状态徽标

状态徽标包括：

当前行动
等待中
UNO
UNO 保护中
可抓 UNO
加牌目标
罚抽目标
已断线
已出局
赢家

要求：

状态文字短，不要撑爆座位。
长昵称要省略或换行。
手牌数要清楚。
任务 4：操作按钮状态更明确

按钮应根据状态禁用或高亮：

不是你的回合：出牌、摸牌、UNO 禁用
没有选牌：出牌禁用
drawStack 目标：结算加牌按钮可用
drawUntilColor 目标：继续罚抽按钮可用
游戏结束：所有操作按钮禁用
未连接：创建 / 加入禁用

禁用按钮应：

不可点击
视觉上变弱
有 title 或点击提示原因
任务 5：中央状态信息条

建议增加或优化中央信息条：

当前：玩家 A 行动
颜色：红色
方向：顺时针图标
加牌：+4

移动端可以压缩成：

玩家A · 红色 · ↻ · +4

要求：

这些信息要比日志更靠近牌桌。
不要让日志抢主要视觉。
任务 6：出局和胜利提示接入

如果 Problem 4 已经完成事件或状态，本阶段负责 UI 呈现：

玩家 xxx 手牌为 xx 张，已出局
玩家 xxx 获胜

要求：

弹窗明显
所有玩家都能看到
游戏结束后按钮禁用
返回大厅入口可用
验收标准

完成后至少满足：

1. 顺时针 / 逆时针不再只用文字。
2. 当前玩家高亮明显。
3. 玩家座位有头像、昵称、手牌数和短状态。
4. 当前行动玩家一眼能看出来。
5. 操作按钮禁用状态明确。
6. 中央牌桌附近有清晰状态信息。
7. 出局和获胜提示明显。
8. 移动端不撑爆。
9. 原有 E2E 不回退。
