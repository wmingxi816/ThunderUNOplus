# 雷霆 UNOplus 项目开发文档

## 方向变更

本项目已经从“微信小游戏 / Cocos Creator”方向切换为“HTML 网页端实时多人卡牌游戏”方向。

继续保留：

- `GAME-RULES.md`
- `CARD-CONFIG.md`
- `packages/shared-types`
- `packages/protocol`
- `packages/uno-core`
- `apps/game-server`
- `tools/simulator`

废弃移除：

- `apps/client-wechat`
- `apps/NewProject`
- Cocos 场景、prefab、Creator 构建说明
- 微信开发者工具、微信小游戏构建、`game.json`、`project.config.json`
- `wx.connectSocket` 适配计划

## 当前可用基线

Phase 1 到 Phase 3C 的代码继续有效。它们提供了网页端需要的核心能力：

- 规则引擎：`packages/uno-core`
- 通信协议：`packages/protocol`
- 共享类型：`packages/shared-types`
- 服务端权威房间：`apps/game-server`
- CLI 与多客户端联调：`tools/simulator` 和 game-server dev scripts

Phase 4A 之后以网页端重新开始。当前已经完成 Phase 4H：UI-DESIGN 对战界面落地，并补完 next-step2 的界面细化。随后补完了 Phase 4I：UI 逻辑与算法补完。

当前还通过 Problem 文档记录阶段内发现的问题、具体修复方案和验收重点。Problem 文档用于跟踪实际试玩和测试中暴露的问题，规则与牌库口径仍以根目录的 `GAME-RULES.md` 和 `CARD-CONFIG.md` 为准。

## 新客户端

`apps/client-web` 是新的网页端入口。

当前职责：

- 使用浏览器 WebSocket 连接 `apps/game-server`
- 创建房间、加入房间、离开房间、开始游戏
- 展示 lobby 房间状态
- 展示 playing 阶段玩家视角快照
- 发送出牌、摸牌、UNO、质疑等命令
- 使用 `public/cards` 中的 PNG 牌面资源
- 使用 `room-state.playerId` 稳定识别当前玩家
- 支持单牌、顺子、连对、同色丢弃的选牌出牌
- 支持黑牌颜色选择弹层
- 支持基于本地 `userId + roomId` 的最小断线重连
- 支持服务端错误和 `command-rejected` 页面提示
- 支持对局结束横幅与结束后操作禁用
- 使用 jsdom 冒烟测试覆盖页面启动和 reconnect 消息
- 支持生产构建和 `vite preview`
- 支持局域网手机 / 电脑访问说明
- 支持 Playwright 真实浏览器 E2E
- 支持三窗口自动化联调回归
- 支持手机和窄屏下的基础布局、触控按钮和手牌区优化
- 支持移动端横屏 / 竖屏、长昵称和日志区滚动收口
- 支持窄屏回归测试 `mobile-layout.spec.ts`
- 支持大厅头像展示和房间内头像不重复分配
- 支持环绕式对战座位、数字手牌数、弃牌堆叠和轻量出牌动画
- 支持质疑弹层和 5 秒视觉倒计时
- 支持摸牌后的临时出牌 / 保留决策流程与罚抽动画提示
- 支持 UNO、淘汰、胜负结算弹窗和结束状态操作禁用
- 支持加牌链、弃牌堆、座位方向和当前玩家状态展示优化
- 支持对战中主动退出房间，并区分主动退出与断线重连
- 支持更严格的组合候选高亮、手牌换行和选中上移动效

网页端禁止承担：

- 判断出牌是否合法
- 自己结算摸牌、罚抽、胜负
- 存储权威游戏状态
- 绕开 `packages/protocol` 直接调用规则

## 本地运行

启动服务端：

```bash
corepack pnpm --filter @thunder-uno/game-server dev
```

启动网页端：

```bash
corepack pnpm --filter @thunder-uno/client-web dev
```

访问：

```txt
http://localhost:5173
```

默认连接：

```txt
ws://localhost:8787
```

局域网设备调试时，网页端地址和 WebSocket 地址都要使用电脑局域网 IP。

## 测试

常用命令：

```bash
corepack pnpm --filter @thunder-uno/client-web typecheck
corepack pnpm --filter @thunder-uno/client-web test
corepack pnpm --filter @thunder-uno/client-web build
corepack pnpm --filter @thunder-uno/client-web test:e2e
corepack pnpm typecheck
corepack pnpm test
```

首次运行 Playwright E2E 前，如果本机没有浏览器依赖：

```bash
corepack pnpm --filter @thunder-uno/client-web exec playwright install
```
