# Phase 7A：对战 UI、音效与房间体验打磨

## 阶段目标

Phase 7A 主要整理近期围绕对战界面的集中打磨：让玩家卡片、牌堆、手牌区、方向提示、音效和设置入口更适合实际多人游玩，同时补齐玩家离线重连、机器人体验、资源压缩和 UI 调试文档。

本阶段不是新增一套规则，而是在 Phase 6A 机器人和房间能力的基础上，把“能玩”继续推进到“多人游玩时更清楚、更稳定、更容易调整”。

## 核心改动

### 1. 对战界面布局

- 对战页拆分并命名了主要 UI 区域，形成 `docs/UI-PART-NAMES.md`，后续可以直接按区域名沟通修改。
- 玩家卡片改为左右两侧排布，并按当前玩家视角计算相对位置，尽量让上下家和顺/逆时针方向在视觉上对应。
- 玩家卡片尺寸会根据人数动态调整，人数较少时更大，人数较多时避免重叠。
- 玩家卡片头像改为背景图，当前行动玩家更亮，非当前行动玩家降低亮度。
- 玩家姓名、手牌数量、抓 UNO 按钮等组件改为在玩家卡片父容器内定位，随父容器缩放。
- 摸牌区、牌堆区、状态提示区、手牌区改为更偏向页面相对位置控制，减少互相挤压导致的位移。
- 顶部状态栏、普通摸牌弹窗、玩家出局弹窗等关键层级提升，避免被牌堆或特效遮挡。

### 2. 牌堆和加牌链 UI

- 牌堆底部保留多张历史牌，形成散乱叠放效果。
- 底牌堆的偏移、旋转和透明度改为稳定布局，避免每次刷新都重新随机导致画面跳动。
- 一次性打出多张牌时，底牌堆按打出数量推进，保留同一组牌的相似位移趋势。
- 顺子出牌时，牌堆 UI 按数字大小排序，确保最小号在底部、最大号在顶部。
- 加牌链进行中使用平铺叠加展示；加牌链被摸牌结算后，旧加牌链转为底牌堆，新加牌重新开启新的链条展示。

### 3. 方向提示和开局方向

- 游戏开局随机选定一号位后，由一号位选择顺时针或逆时针。
- 对战区加入顺/逆时针旋转方向底图。
- 顺时针和逆时针使用两张图片资源，其中逆时针图由顺时针图镜像生成。
- 打出反转牌或反转变色 +4 后，方向提示会随游戏方向更新。

### 4. 音效和背景音乐

- 新增音效目录 `apps/client-web/public/sounds/`。
- 大厅背景音乐支持多首随机播放，对战页使用独立对战音乐。
- 设置面板支持背景音乐和音效音量调节。
- 音量滑轨支持 `0% - 120%`，并带有禁音按钮。
- 禁音按钮在静音时显示红色，再次点击恢复静音前音量并显示绿色。
- 罚抽音效按摸牌次数递减播放速度，摸到目标颜色时播放结束音效。
- 加牌相关音效按行为拆分：
  - 打出或叠加 `+2`、普通 `+4`、黑色反转 `+4` 时播放 `进行加牌1`。
  - 打出或叠加 `+6`、`+10`，以及打出交换手牌时播放 `进行加牌2`。
  - 加牌链结算摸牌数大于等于 10 时播放 `被加牌1`。
  - 加牌链结算摸牌数小于 10 时播放 `被加牌2`。
- 被加牌本人听到的音效更大，其他玩家听到的音效更小。

### 5. 对战特效

- 玩家被加牌链结算时，在对应玩家卡片位置播放爆炸特效。
- 加牌数量越多，爆炸范围越大，并按指数趋势增长。
- 罚抽摸牌时，在对应玩家卡片位置喷出问号特效。
- 第 n 次罚抽摸牌会喷出 n 个问号，颜色从红、黄、蓝、绿中随机。
- 特效位置跟随每个玩家视角下的玩家卡片位置，而不是固定使用全局坐标。

### 6. 设置面板

- 对战页顶部加入设置按钮。
- UI 缩放支持四档：`60%`、`80%`、`100%`、`120%`。
- 背景音乐和音效改为滑轨调节。
- 设置面板加入显示/关闭调试网格按钮，方便继续做尺度调整。
- UI 缩放、背景音乐、音效和网格开关都会写入本地存储。

### 7. 大厅和房间体验

- 大厅支持改名按钮，玩家在昵称输入框修改后点击改名，其他玩家画面同步更新。
- 玩家身份使用隐藏唯一标识，不依赖昵称匹配；改名不会改变玩家身份。
- 玩家退出后，房间仍存在时保留等待席位。
- 退出期间玩家卡片保留，行动回合会跳过离线/退出玩家。
- 玩家重新通过房间号加入后，继续使用原来的手牌和状态。
- 胜利玩家离开后再回来，仍保留胜利状态；胜利玩家离线时使用绿色框提示。
- 游戏结束后，房主点击重新开始时会清理仍未回到房间的旧玩家。
- 大厅机器人条目精简显示，但保留头像。
- 可选种子输入框在玩家界面隐藏。

### 8. 机器人体验

- 机器人名称调整为 `雷霆bot` 系列。
- 机器人摸牌动作延迟调整，普通摸牌和罚摸更像真人操作。
- 机器人贪心策略补充交换手牌权重：当手牌质量较差或手牌过多时，动态提高交换手牌分数。
- 机器人普通数字牌策略补充：优先打出不参与顺子/对子、且距离手牌数字平均值更远的数字牌。
- 增加兜底出牌保护，避免候选牌同分或评分异常时机器人不行动。

### 9. 资源和文档

- 压缩大厅背景、对战背景和头像资源，降低加载体积。
- 新增 `docs/UI-PART-NAMES.md`，给大厅和对战页主要区域命名。
- 更新 README 为面向玩家的说明文档，包含规则、图片和启动方式。
