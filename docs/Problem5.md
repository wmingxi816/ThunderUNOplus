# Problem 5：弃牌堆、加牌链展示与出牌 / 摸牌动画

## 问题背景

当前对战页的牌桌表现还不符合想要的卡牌对战感。弃牌堆没有真正形成“打牌一样的散落牌堆”，多牌出牌、同色丢弃和加牌链没有专门展示，出牌和摸牌动画也需要优化。

本问题对应原问题：

- 4. 摸牌应该有牌落入手牌堆的动画
- 15. 弃牌堆应该随机散落，顺子 / 连对 / 同色丢弃 / 加牌链有不同表现
- 16. 玩家出牌动画需要从头像附近冒出来，旋转后落入牌堆

## 本阶段目标

实现牌桌视觉和动画系统：

1. 弃牌堆表现为有厚度的散落牌堆。
2. 刚出的牌摆正并黄色框高亮。
3. 历史牌轻微旋转、偏移，叠在底下。
4. 顺子、连对以扇状展示。
5. 同色丢弃以扇状展示，但同色丢弃牌放最上方。
6. 加牌链集中放在牌堆正中最上方，并黄色高亮。
7. 加牌链结算后散开到弃牌堆。
8. 玩家出牌从头像或手牌区飞向中央牌堆。
9. 摸牌从牌堆飞向玩家手牌区或头像区域。

## 不要做什么

本阶段不要做：

- 不修改核心规则。
- 不修改牌库配置。
- 不做登录、数据库、支付、商城。
- 不做大规模 UI 架构重写。
- 不影响现有 E2E 选择器。
- 不牺牲移动端基本可用性。

## 需要检查的文件

请优先审计：

1. `apps/client-web/src/main.ts`
2. `apps/client-web/src/styles.css`
3. `apps/client-web/src/cards/cardAssets.ts`
4. `packages/shared-types/src/event.ts`
5. `packages/shared-types/src/snapshot.ts`
6. `packages/protocol/src/messages.ts`
7. `apps/game-server/src/broadcast/sendSnapshotsToRoom.ts`

## 任务 1：弃牌堆基础散落效果

弃牌堆不要只显示一张当前牌。

要求：

```txt
1. 保留最近若干张可视弃牌。
2. 历史弃牌随机轻微位移和旋转。
3. 刚出的牌放在靠中间位置，角度较正。
4. 刚出的牌有黄色边框高亮。
5. 更早的牌用压缩阴影表现厚度。

建议范围：

平移：-8px 到 8px
旋转：-10deg 到 10deg
最近可视层：5 到 8 张

不要渲染全部弃牌，避免 DOM 过多。

任务 2：顺子 / 连对扇状展示

当玩家一次出多张牌，例如顺子或连对：

这些牌应该以扇状排列，
每张牌露出一部分，
整体落入弃牌堆。

要求：

1. 多张牌不要完全重叠。
2. 每张牌都露出部分牌面。
3. 最新组合整体黄色高亮。
4. 组合进入弃牌堆后，历史状态可以压缩为一组。
任务 3：同色丢弃展示

同色丢弃出牌时：

依旧使用扇状展示。
但“同色丢弃”那张牌必须放在最顶上。

例如：

绿同色丢弃 + 绿2 + 绿禁

展示顺序：

底层：绿2、绿禁
顶层：绿同色丢弃
任务 4：加牌链集中展示

加牌链展示是独立规则。

要求：

1. 第一张 +2 先按普通出牌放置。
2. 如果后续有人继续叠加加牌牌，
   这些牌立刻组成加牌链 UI。
3. 加牌链牌全部黄色边框高亮。
4. 加牌链放在牌堆正中最上方。
5. 一张叠一张，整齐长方形排列。
6. 直到某玩家吃下这堆加牌。
7. 玩家吃下后，这条加牌链用动画散开到弃牌堆各处。

加牌链包含：

普通 +2
普通 +4
反转 +4
+6
+10
罚抽叠加链
任务 5：出牌动画

玩家出牌动画要求：

玩家出的牌从玩家头像附近冒出来，
经过轻微旋转，
飞到中央弃牌堆，
落下后进入对应弃牌堆布局。

本地玩家：

可以从手牌区出发。

其他玩家：

必须从该玩家头像或座位区域出发。

不要从固定中心突然出现。

任务 6：摸牌动画

摸牌动画要求：

牌从摸牌堆飞向玩家。

本地玩家：

牌飞向手牌区，
落入手牌，
刚摸到的牌红圈提示。

其他玩家：

牌背飞向该玩家头像或座位，
该玩家手牌数量增加。
任务 7：动画不能破坏规则状态

所有动画必须是表现层。

要求：

1. 规则结果以服务端 snapshot 为准。
2. 动画中不能产生额外规则状态。
3. 动画失败不能导致对局卡死。
4. 动画结束后 UI 与最新 snapshot 对齐。
验收标准

完成后至少满足：

1. 弃牌堆有散落层次。
2. 刚出的牌黄色框高亮。
3. 顺子和连对扇状展示。
4. 同色丢弃牌在组合最上方。
5. 加牌链集中居中高亮展示。
6. 加牌链结算后散开。
7. 出牌动画从玩家头像或手牌区飞向牌堆。
8. 摸牌动画从牌堆飞向玩家。
9. 移动端不明显撑爆。
10. 原有 E2E 不回退。
测试命令

corepack pnpm --filter @thunder-uno/client-web test
corepack pnpm --filter @thunder-uno/client-web test:e2e
corepack pnpm --filter @thunder-uno/client-web build
corepack pnpm typecheck
